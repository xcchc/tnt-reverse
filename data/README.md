## 脱敏说明

抓包样本做过以下处理。**字段编号、wire 类型、嵌套层级一律原样保留**——
794 帧逐帧比对过，结构零差异；变的只有文本内容。

| 处理 | 原值 | 现值为 |
|---|---|---|
| 玩家昵称 | 真实 ID | `玩家NN` / `玩家` |
| 会话 token | 随机 16 字节 | 全 `0` |
| 服务器地址 / 内网 IP | 真实地址 | 文档保留段（`203.0.113.x`、`192.0.2.x`、`198.51.100.x`） |
| 邮件 UUID | 真实 UUID | 全 `0` |
| 邮件标题 | 含日期与版本号的运营标题 | `例行版本更新公告` |
| 公告正文 / 系统播报 | 运营 HTML 富文本 | `公告内容` / `系统播报` |
| 群号 | 官方 QQ 群号码 | `官方群` |
| 头像图床 URL | 真实 CDN 链接 | `<url>` |
| `tree` 字段 | 导出时的解析缓存 | 删除（可用 `tools/frame.py` 重算） |

**保留未改**的是协议结构常量，改了会误导实现者：

```
频道名   system / global / server / 系统 / 全服 / 大区 / 附近
伤害文案 失去生命60点 / 失去生命70点 / 失去生命80点 / 吸收生命84点
```

## 一个注意点

替换昵称会改变帧长，因此脱敏后 `msg_id`（等于帧头 `msg_len`）
与按当前内容重算的长度不再相等。这是脱敏的正常代价；
长度关系本身已在原始数据上验证过（12,013 帧，零不一致），
结论写在 `docs/02-protocol.md` 2.4 节。
